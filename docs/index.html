Programmer en français

Baobab est un langage de programmation écrit en français, pour apprendre la logique avant de passer à Python. Il traduit ton code en Python, l’exécute, et explique tes erreurs en français.

Pourquoi un langage en français

Presque tous les langages utilisent des mots anglais : if, for, return, print. Pour un débutant francophone, c’est une difficulté de plus avant même de comprendre la logique.

Baobab remplace ces mots par si, pour, retourner, afficher. Tu te concentres sur l’idée : les variables, les conditions, les boucles, les fonctions. Quand tu es à l’aise, tu passes à Python et tu retrouves les mêmes idées.

Il s’adresse aux débutants francophones, aux enseignants qui veulent un outil en français, et à ceux qui veulent écrire vite un petit site ou une API.

Comment ça marche

  1. Tu écris ton programme dans un fichier .bao.
  2. Baobab traduit les mots français en Python, mot à mot. Les textes entre guillemets et les commentaires ne sont jamais modifiés.
  3. Python exécute le résultat.
  4. Tu vois ce que le programme affiche, ou un message d’erreur en français.

Tu peux regarder la traduction quand tu veux :

baobab programme.bao             lance le programme
baobab python programme.bao      montre le Python généré
baobab expliquer programme.bao   chaque ligne et son équivalent Python
baobab tester exemples           lance les tests écrits en Baobab
baobab                           mode interactif

Variables et affichage

Une variable garde une valeur sous un nom. afficher l’écrit à l’écran.

age = 15
afficher("Mon age est", age)

Calculs

Baobab calcule comme une calculatrice : + - * /.

prix = 1500

Des erreurs qui aident

Quand tu te trompes, tu n’as pas un message anglais cryptique. Voici un vrai message de Baobab, obtenu quand une méthode n’existait pas encore :

💥 Impossible de charger ce fichier
   ligne 85 : serveur.documenter("/documentation", "API des notes")
   Cet objet n'a pas de 'documenter'. Vérifie le nom de la méthode.

Le message donne la ligne, le code en cause et un conseil. Quand tu fais une faute de frappe, Baobab propose le nom le plus proche.

Un site web en quelques lignes

Baobab contient un serveur web. Voici la page d’accueil d’une application de notes, simplifiée à partir de exemples/notes_installable.bao :

importer serveur

NOTES = []

fonction accueil(parametres, demande):
    liste = serveur.repeter("<li>{{element}}</li>", NOTES)
    contenu = serveur.modele("<h1>Mes notes</h1><ul>{{liste|brut}}</ul>", {"liste": liste})
    retourner serveur.page("Mes notes", contenu)

serveur.route("/", accueil)

si programme_principal:
    serveur.demarrer(8000)

route relie une adresse (ici /) à une fonction. modele fabrique le HTML et protège les textes. demarrer(8000) lance le site : tu l’ouvres sur http://127.0.0.1:8000.

La sécurité, expliquée

Un site reçoit des données de gens qu’on ne connaît pas. Baobab protège les cas les plus courants sans que tu aies à y penser :

HTML protégé
Si un visiteur écrit du code dans un formulaire, il s’affiche comme du texte et ne s’exécute jamais. Le marqueur |brut coupe cette protection : réserve-le au HTML que tu as fabriqué toi-même.
Mots de passe
Jamais gardés en clair : seule une empreinte est enregistrée (PBKDF2-SHA256, 600 000 itérations).
Trop d’essais
limiter refuse les demandes trop fréquentes. L’exemple d’espace membre bloque après 5 échecs de connexion.
Champs inattendus
valider ne garde que les champs que tu as décrits : un visiteur ne peut pas en ajouter d’autres.
Fichiers publics
Le serveur refuse de sortir du dossier public, d’ouvrir les fichiers cachés ou de suivre les liens symboliques.
Cookies et JSON
Les cookies de session sont protégés (HttpOnly, SameSite). Un JSON énorme ou trop profond est refusé.

L’essayer

Baobab n’est pas encore publié sur PyPI : on l’installe depuis GitHub. Il faut Python 3.9 ou plus récent.

git clone https://github.com/daboujohan-hub/Abou-Johan-Baobab-V0.0.git
cd Abou-Johan-Baobab-V0.0
python -m baobab lancer exemples/bonjour.bao

Questions fréquentes

Faut-il connaître Python ?

Non. Baobab est fait pour commencer. Python devient utile plus tard.

Puis-je utiliser les modules de Python ?

Oui. Les modules standard de Python s’importent aussi avec importer.

Baobab est-il rapide ?

Il a la même vitesse que Python, car il s’appuie dessus.

Puis-je l’utiliser pour un vrai site public ?

Il convient pour s’entraîner et pour de petits projets. Son serveur est éducatif : pas de HTTPS intégré, sessions gardées en mémoire. Il n’a pas été audité par un tiers : ne l’utilise pas pour des données bancaires ou de santé.

Sur quels systèmes fonctionne-t-il ?

Il a été testé sous Android (Termux) et Linux. Windows et macOS n’ont pas été vérifiés.

Est-il gratuit ?

Oui, sous licence MIT.

Où en est le projet

Le développement est mis en pause à la version 0.16.0. Le code, les tests et la documentation restent sur GitHub pour le reprendre plus tard. Un prototype d’application d’apprentissage (leçons et éditeur) se trouve dans le dépôt : il n’est pas terminé.
